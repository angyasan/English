🔑 合鍵（GitHubのアクセストークン）

  • 期限：2027年9月30日
  • 期限が切れると、「＋追加」で送信したときに「合鍵が正しくないか、期限が切れています」と表示されます。
  • そのときは同じ手順で作り直してください：
    github.com/settings/personal-access-tokens/new を開く → 名前・期限を入れる → Repository access は「Only select repositories」で angyasan/English → Permissions に「Contents」を追加して「Read and write」 → Generate token → 出てきた文字列を Safari で開いた単語帳の「＋追加」→「🔑 合鍵の設定」に貼って保存

📴 ネットがなくても使う

  • ネットにつながった状態で一度開けば、単語帳は自動で iPhone に保存され、ネットがなくても開けます（Safari で開いてください）。
  • 音声は、一度鳴らしたものは自動で保存されます。全部まとめて保存するには下のボタンを押してください（約30MB。Wi-Fi のときがおすすめ）。
  • ネットがないときは「＋追加」の送信はできません（書きかけは残ります）。辞書音声は使えないので、AI音声で鳴ります。
  • Safari で長いあいだ（7日以上）開かないと、保存した分が消されることがあります。そのときはネットにつながった状態で開き直し、ボタンでもう一度保存してください。

🔊 Google の音声（AI音声）の無料枠

  • 期限：2027年1月14日
  • そのあとも新しい単語の音声を作り続けるには、Google Cloud のアカウントを有料版に切り替える必要があります。
Q. 期限を過ぎたら、新しい単語だけ音声が作られなくなる？すでにある音声は？
  • 止まるのは、新しく追加した単語の音声づくりだけです。
  • すでにある音声は mp3 ファイルとしてリポジトリ（audio フォルダ）に保存されていて、再生のときは Google にアクセスしません。期限が過ぎても消えたり鳴らなくなったりしません。
  • 期限後に追加した単語も、追加自体は普通にできます。AI音声がないだけで、再生すると iPhone 本体の読み上げに自動で切り替わります。GitHub から「音声生成が失敗しました」という通知メールが届くことがあります。
  • あとで有料版に切り替えれば、次に音声を作るタイミングで、AI音声がない単語の分もまとめて自動で作られます。
  • 期限が来ても勝手に課金は始まりません（切り替えは自分で操作が必要）。切り替えたあとも、1日に数語追加する程度なら、ほぼ無料〜数円の見込みです。
